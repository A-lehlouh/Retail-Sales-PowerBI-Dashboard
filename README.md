#  Retail Sales Power BI Dashboard

An interactive Power BI dashboard that analyzes retail sales data across major Middle East cities. The dashboard provides insights into sales performance, profit margins, and quantity sold — broken down by product, category, and region.

---

## Dataset

- **File:** `RetailSalesData.xlsx`
- **Columns:**
  - `Date` — transaction date (2024)
  - `Product` — product name (Laptop, Smartphone, Headphones, T-Shirt, Jeans, Jacket, Boots, Sneakers, Sandals)
  - `Category` — Electronics, Clothing, Footwear
  - `Region` — Dubai, Riyadh, Kuwait, Doha, Jeddah, Manama
  - `Sales Amount` — total sales value
  - `Quantity` — number of units sold
  - `Profit` — profit per transaction

---

## Dashboard Highlights

- **Sales by Region** — compare performance across 6 Middle East cities
- **Sales by Category** — Electronics vs Clothing vs Footwear
- **Sales by Product** — top performing products
- **Profit Analysis** — profit trends over time
- **Monthly Trends** — sales and profit over Jan–Jun 2024

---

## Tools Used

- **Power BI Desktop** — dashboard creation and visualization
- **Microsoft Excel** — data source

---

## How to Use

1. Download `RetailSalesData.xlsx` and `project1.pbix`
2. Open `project1.pbix` in **Power BI Desktop**
3. If prompted, update the data source path to point to `RetailSalesData.xlsx`
4. Explore the interactive dashboard
